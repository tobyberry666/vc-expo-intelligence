# 情报更新可靠性实施计划

目标：每小时检查公开新闻与官方展会来源，浏览器持续展示服务器最新快照；失败及过期有明确提示，不承诺全网无遗漏。

1. 为网络重试、展会日期解析、单源时间保留添加失败测试，再修改 `scripts/collect-feed.py`。验证离线测试和真实采集。
2. 将 `.github/workflows/pages.yml` 改为每小时运行，限制任务时长；更新来源状态中真实检查时间及成功时间。全新闻源失败停止发布。
3. 给共享 store 加一个订阅期间的五分钟刷新定时器，防止页面长时间停留旧版本；超三小时未采集提示延迟。验证多订阅只创建一个定时器、取消订阅停止刷新、不重叠请求。
4. 更新数据边界文档，执行完整质量和浏览器检查；提交、云端 CI、发布并读取线上快照核实结果。

已知边界：GitHub 调度可能延迟，公开仓库 60 天无活动可能停用定时任务；新增来源和新一届展会仍需要核实，未知字段不补造。
